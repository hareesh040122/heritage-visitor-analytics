### Design Overview

The Mock UX demonstrates the primary screens, navigation structure, and major user journeys of the Heritage Visitor Analytics application.

It includes:
- Dashboard with visitor KPIs and analytics charts.
- Visitor analytics and filtering.
- Heritage site performance.
- Reports and CSV export.
- Visitor data upload and validation.
- Error and empty states.

The design focuses on usability, clear information hierarchy, and helping heritage-site managers understand visitor engagement and performance.
